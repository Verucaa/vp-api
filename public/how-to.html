TIPS PENGGUNAAN

Format request dan respons.

01

Tanpa autentikasi

Jangan menambahkan header API key. API memakai batas default 100 request per menit per alamat IP.

02

GET atau POST

Endpoint yang menerima parameter mendukung query string pada GET dan JSON pada POST. Untuk `token` atau data sensitif, gunakan POST agar tidak masuk ke URL.

03

Format respons

Respons sukses berbentuk JSON dengan `status`, `creator`, dan `result`. Periksa status HTTP untuk menangani error seperti 400, 429, atau 502.
